# Age Prediction App

## Project Overview
This project uses deep learning and a Convolutional Neural Network (CNN) to predict a person's age from a facial image. The model is trained using facial images from the UTKFace dataset.

## Objectives
- Develop an image-based age prediction model using TensorFlow and Keras.
- Preprocess facial images for input into a neural network.
- Train and evaluate the model's performance.
- Deploy an interactive web application that allows users to upload an image and receive an estimated age prediction.

## Dataset
The project uses the UTKFace dataset, which contains facial images of people of different ages. The age label is encoded in the image filename.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Streamlit

## Model Development
The project includes image loading and preprocessing, dataset preparation, neural network development, model training, and evaluation. The trained model is used to predict age from new facial images.

## How to Use the Application
1. Open the deployed application using the link below.
2. Upload a facial image or take a picture of your self.
3. Run the prediction.
4. View the estimated age returned by the model.

## Live Application
**Deployed App:** [https://age-prediction-sara.streamlit.app/]

## Limitations
The predicted age is an estimate and may differ from a person's actual age. Prediction accuracy can be affected by image quality, lighting, facial expressions, and the diversity of the training dataset.
